## 📋 **Getting Started**

### **For Users:**
1. **Create Account**: Sign up and log in
2. **Build Resume**: Add your information section by section
3. **AI Analysis**: Get instant feedback and suggestions
4. **Generate PDF**: Download professional resume
5. **Create Variations**: Generate different versions for different jobs

### **For Developers:**
1. **Clone Repository**: Get the source code
2. **Install Dependencies**: `pip install -r requirements.txt`
3. **Run Migrations**: `python manage.py migrate`
4. **Start Server**: `python manage.py runserver`
5. **Access Admin**: Create superuser for management
